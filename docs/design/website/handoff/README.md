# ghostframe website

The design for the ghostframe website, direction **The Frame**, and everything needed to build it.

- Start with `HANDOFF.md`. It is the build brief, written for Claude Code.
- Open `reference/index.html` in a browser to see the design. Every page opens from disk.
- `ACCEPTANCE.md` is the definition of done. `REVIEWS.md` records the design reviews.
- `build/` holds the sources the site imports: tokens, motion, content, the demo session, the glyph field.
- `tools/` holds the generator for the glyph field and the tests the reference passes.
- `screenshots/` and `filmstrips/` are what the build is compared against.

To build it, ask Claude Code: "Read docs/design/website/HANDOFF.md and build the site as it describes."
