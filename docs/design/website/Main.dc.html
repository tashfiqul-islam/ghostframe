Product brief: the website

Mode: Persuade. One long landing page, a 404 and a changelog. Written from sections 1 to 4 of the design brief; nothing here is new product truth.

Job and audience

  • Developers who spend the day in a terminal with Claude Code. Sharp, allergic to marketing, moved by craft, speed and honesty.
  • They arrive from GitHub, a post or a screenshot, on a laptop, mid-task. Many will scan for under a minute.
  • The site has to answer three things fast: what it is, whether it runs on my setup, and how to install or remove it.

Outcome and proof

  • Primary action: copy the install command. Secondary: open the GitHub repo.
  • Proof is the product itself: Cockpit and the status line rebuilt as live HTML, playing a scripted session.
  • Only ghostframe can show a ghost whose eyes report your budget. That is the idea the page is built on.
  • No testimonials, logos, download counts or star counts unless fetched live.

Direction

  • Concept: the ghost in the frame. Dark, quiet, precise, with one warm light.
  • Chosen: The Frame. One rectangle is the lens, the terminal window, the meter and the ghost's slot.
  • Fixed whichever wins: the palette, the two type families, the mascot artwork, the voice.

Scope and boundaries

  • This round: the chosen direction as key frames at 1440. Next: the full page at 1440 and 390, the 404, a component sheet and a motion spec. Then the build.
  • Untouched: every brand asset, the eye thresholds (60 and 85), product facts.
  • Wrong even if polished: a cyberpunk poster, neon, Matrix rain, gold used as a theme colour, icon cards in place of real UI.

States and ranges

  • Budgets from unknown (a dash, never a fake 0%) through calm, amber and red, with notes at 85 and up.
  • The demo: playing, paused, finished, reduced motion, and a text alternative.
  • Copy command: idle, copied, clipboard blocked. Star count: loaded or absent.

Interaction and layout

  • A strict 12-column grid with deliberate breaks; hairlines and surface steps in place of shadows.
  • One orchestrated motion language: ease-out, 180 to 600 ms, scroll-scrubbed only for the signature moments.
  • On phones the terminal becomes a cropped, swipeable view. It is never squashed.
  • Everything interactive has a visible gold focus ring and works from the keyboard.

Constraints

  • Static site on Cloudflare Pages. Astro 5, React islands, Tailwind v4, shadcn/ui.
  • Lighthouse 95+, LCP under 1.8 s, CLS 0, about 120 KB of JavaScript on first load.
  • WCAG 2.2 AA. Dark by default; a light theme only if it is as good.

Decisions

  • Direction: The Frame. One rectangle is the lens, the terminal, the meter and the slot.
  • Dark only for 1.0.0.
  • The loader is a 1.8 s curtain over a page that is already painted. Once per session, skippable.
  • Small labels use #8C8899. The brief's #6E6A7A fails AA, so ruler numerals use #7F7B8B.
  • Prose is set in Hanken Grotesk 400.
  • How it works shows two paths, as the status line doc describes.
  • Facts are checked against the public repo at df9ab55: install commands, no network code, Claude Code 2.1.329 up to 2.2.0, where it is tested.
  • Release notes get their own page, generated from the changelog. The nav is a small frame; the repository link is an icon.
