file 10 · faq · 7 questionsrows 567 to 623

Questions.Questions.Questions.

The status line installer writes one key, statusLine, in your user settings. It shows the diff first, waits for you, and keeps a backup. Every other key, its order and the formatting stay as they were.

Claude Code keeps only colour codes and links from a status line and drops everything else, images included. So inside the terminal the ghost is drawn in half blocks.
