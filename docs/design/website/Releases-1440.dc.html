ghostframe 1.0.0ghostframe 1.0.0ghostframe 1.0.0

A Claude Code plugin with two parts. Cockpit is a redesigned chat UI: the conversation on the left, and the work of each turn on the right, in a pane with its timeline, files, sources, to-do and agents. The status line shows the model, the repository, your context and your 5-hour and weekly budgets in two rows, with a ghost whose eyes show the pressure.

The status line

Installed with one command: model and effort, repository and branch, context, and the 5-hour and weekly budgets with their pace and reset times.

Also in 1.0.04

default
Cockpit is on by default

It starts as soon as the plugin loads. Turn it off with Cockpit pane in /config, or for one session with GHOSTFRAME_COCKPIT=0.

engine
It stays out of the way on untested versions

ghostframe declares the Claude Code versions it is tested with, >=2.1.329 <2.2.0. On any other version it goes dormant, hands every row back, and says so once.

install
Install from the marketplace

The repository is its own plugin marketplace. Two commands install ghostframe, and Claude Code offers each new version as an update.

security
Two security fixes in the status line

It now strips every control character from outside text, such as a folder or branch name. Its caches moved from the shared temp folder to your own cache folder, readable only by you.

Requirements

  • Claude Code 2.1.329 up to, not including, 2.2.0, in a terminal. Outside that range ghostframe stays dormant.
  • Windows is tested live. Linux in CI and WSL. macOS in CI only.
  • A Nerd Font for the status line's icons (optional), and Bun for the status line.

Known limits

  • The Files tab keeps the counts tallied from the turn's steps. Only the selected file is diffed.
  • Files outside the project are listed but never diffed.
  • Cockpit draws in the terminal only, not in Claude Code's Desktop app or VS Code panel.
