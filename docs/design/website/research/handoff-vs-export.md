# Handoff vs export: disagreements that change the build

Compared on 2026-11-28, read-only.

- **Export (newer):** `D:\Projects\ghostframe-wt\website-stack\docs\design\website\*.dc.html` + `canvas.json`.
- **Handoff (older):** `...\website\handoff\` (HANDOFF.md, ACCEPTANCE.md, REVIEWS.md, build/, reference/).
- **Rule applied:** the export wins unless the handoff explicitly says it supersedes. Where the handoff wins, the row
  quotes the handoff's own words.

## Method, and what turned out to be identical

All 17 boards were compared with their `reference/<same name>.html` counterpart on three axes. The scripts and outputs
are in `scratchpad\cmpscripts\` and `scratchpad\cmp\`.

1. **Visible text.** Tags were stripped and the text diffed line by line. Apart from the reference's added
   `Skip to content` link and its docked-nav copy, the text is identical on all 17 boards. The rest of the diff was line
   wrapping only.
2. **Every inline `style=""` declaration.** Values were normalised for case, spacing, `0.x`, and `.0px`. They are
   identical except for the items in rows 28 to 31 (img versus canvas, the boot eyes, the root element and overflow,
   and the docked-bar instance).
3. **Every `<style>` rule and `@keyframes`.** All 48 boot keyframes, `gl`/`gl2`/`scanb`/`hot`/`jit`/`dimr`/`tearl`/`pc`,
   and the nav/rail rules match. Only trailing-zero formatting differs (`1.500%` against `1.5%`).

So `reference/*.html` is the export plus a hardening pass. Almost every real disagreement sits **between the export
boards (and therefore the reference) and the handoff's prose and data files**: HANDOFF.md, content.ts, releases.ts,
tokens.css and motion.css.

### Shared defect (both sides, so not a disagreement)

147 CSS values in the export, and the same 147 in reference/, read the literal text `<function <lambda> at 0x…>` where
a colour should be. The breakdown is 20 `box-shadow: inset 0 0 0 1px …`, 7 `border: 1px solid …` and 4
`repeating-linear-gradient(90deg, … 0 1px, …)` in Components alone. They also appear in Page-1440-b (30), Page-390-b (24),
Releases-1440 (23), Releases-390 (16) and others. The declarations are invalid, so those outlines, borders and ruler
ticks render in neither copy. That covers the secondary buttons, the menu's Docs/Source buttons and the title-block
tick bands. Neither side says what the value should be. The nearest live equivalents are `#1E1D24` (`--line-1`) and
`#2A2A34` (`--line-2`). Not verified.
