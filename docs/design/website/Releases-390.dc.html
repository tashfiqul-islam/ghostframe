ghostframe 1.0.0ghostframe 1.0.0ghostframe 1.0.0

A Claude Code plugin with two parts. Cockpit is a redesigned chat UI: the conversation on the left, the work of each turn on the right. The status line shows the model, the repository, your context and your budgets in two rows.

Requirements

  • Claude Code 2.1.329 up to, not including, 2.2.0, in a terminal.
  • Windows is tested live. Linux in CI and WSL. macOS in CI only.
  • A Nerd Font for the icons (optional), and Bun for the status line.

Known limits

  • Only the selected file is diffed; the rest keep their tallied counts.
  • Files outside the project are listed but never diffed.
  • Cockpit draws in the terminal only.
