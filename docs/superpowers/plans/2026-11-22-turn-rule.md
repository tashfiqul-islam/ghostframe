# Turn rule (E.1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** While Cockpit is on, every typed prompt opens with E.1's rule `─ [ TURN n ] ─── 09:23`, n being the step log's turn number.

**Architecture:** Each prompt stamp (`PromptStamp`, kept in `$.state` and in `$.store` under `prompts:<session id>`) gains the
row id it is drawn under, its turn number and what came before it (resume, compaction, rewind). The ledger writes them at
`session.append` (row), `turn.start` (number, label state) and `session.compact` / session start (pending state). The prompt site
reads them, from the store before `session.start`, and draws the rule from a pure function. Cockpit off keeps the v6 rule.

**Tech Stack:** TypeScript/TSX run by the Claude Code plugin engine; tests with `claude-code/testing` (`bun run --cwd tools test`).

**Spec:** `docs/design/cockpit-v7.md` E.1, E.22, E.23, E.29, C.1; `docs/design/cockpit-v7-amendments.md` 3, 8, 9, 10, correction A.

## Global Constraints

- Rule anatomy: `─` at column 0, `[ TURN n ]` from column 2, solid `─` fill, 24-hour clock ending on the receipt's right edge.
- The rule's width is the receipt's: `ruleWidth(lay) ?? lay.width` for `lay = layout(e.viewport.columns)`.
- Label states: `[ TURN n · RESUMED ]`, `[ TURN n · AFTER COMPACT ]`, `[ TURN n · AFTER REWIND ]`.
- Another calendar day than the previous stamp's: clock `Thu 19 Nov · 09:02`.
- Below 40 cells the clock may go; the label never does.
- Colours (E.1 paint): `─` and fill `C.rule`; `[`, `]` `C.dim`; `TURN n` `C.textBright`; state and clock `C.muted`.
- Cockpit off, or a row in the `full` mode: draws exactly as before (v6 `Rule()`).
- Every `$.ui.log` a person sees starts `ghostframe:`/`cockpit:`; traces pass `{ to: 'debug' }`.

## Review Focus

- A prompt queued while a turn runs: its row draws before its turn starts; it shows the predicted number (log's + 1) and corrects in fullscreen. Test in Task 3.
- Agent reports between typed turns: no rule, no number used. Test in Task 4.
- Resumed transcript drawn before `session.start`: number and time from the store. Test in Task 4.
- The `placeholder` stand-in: shows the number and time, claims neither. Test in Task 3.
- A narrow terminal (fallback at 40 columns and less): label whole. Test in Task 1.

### Task 2: Stamps carry row, number and state

**Files:**

- Modify: `types/index.d.ts` (`PromptStamp`), `hooks/transcript/ledger/state.ts`, `hooks/transcript/ledger/turns.ts`,
  `hooks/transcript/ledger/session.ts`
- Test: `tests/transcript/ledger/stamps.test.ts`

**Interfaces:**

- `PromptStamp = { text: string; at: number; row?: string; turnNo?: number; after?: TurnAfter }`; atom shape `prompts-2`.
- `state.ts`: `notePending($, after: TurnAfter | null)`, `takePending($): Promise<TurnAfter | undefined>` (atom `pendingAfter`);
  `readPromptsNow($)`: the state's list, or before the session started with an empty state, the store's.
- `prompt.submit` (typed, Cockpit on): stamp gets `turnNo` = max(log turnNo, stamps' turnNo) + 1 (prediction).
- `turn.start` (typed): stamp with `at` = the claimed submit gets the log's `turnNo` and `after` = pending, else `'rewind'` when
  `$.session.messages({ after: previous stamp's row })` denies; pending cleared; stamps kept in the store.
- `session.append` door `prompt` (main loop): the newest stamp without a row whose text the message holds gets `row = e.uuid`.
- `restorePrompts`: an empty state taking the store's stamps (a resume) sets pending `resume`.
- `session.compact` (main loop, trigger not `precompute`, not skipped) sets pending `compact`.

- [ ] Tests: number and row written live; agent-report turn (`at` undefined) writes none; resume sets `RESUMED` on the next typed
      turn only; a compaction sets `AFTER COMPACT`; `messages` deny sets `AFTER REWIND`; store holds the fields.
